# Skill-heroes-2026

This is a pre round for the national competition skill heroes.
This project has been made in 3 hours without any AI.

To run this website you will need to use docker or any other local host that supports PHP MY ADMIN.
Once that is running you need to create a database named DreamDestinations and a table named destinations.
When your done with that go to the assets file and import the sql into your newly made table.
Once you do that the desinations should start loading in.
